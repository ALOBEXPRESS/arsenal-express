## Pacotes a serem instalados:

1. **@dnd-kit/core** - Drag & drop framework
2. **@dnd-kit/sortable** - Sortable lists (reordenar cenas)
3. **@dnd-kit/utilities** - Utilities para dnd-kit
4. **react-player** - Player de vídeo/áudio
5. **react-dropzone** - Upload de arquivos drag & drop
6. **sonner** - Toast notifications
